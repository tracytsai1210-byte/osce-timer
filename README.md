# OSCE 考站計時器 V02

中國醫藥大學附設醫院 教學部｜OSCE 考官用倒數計時器（單頁靜態網站，無後端、無資料庫）。

## 檔案結構

```
osce-timer/
├─ index.html      頁面結構
├─ css/style.css   版面與色彩（含深色模式，所有顏色由 :root token 控制）
├─ js/app.js       計時邏輯、紀錄、提示音、設定儲存
├─ vercel.json     Vercel 靜態部署設定（可省略）
└─ README.md
```

## 功能

- 閱題 → 測驗 兩段倒數，環形進度＋大字顯示；剩餘 N 秒轉橘提示，時間到轉紅、持續響鈴直到按停
- 一鍵「下一位」：自動記錄本位學員用時、是否超時，學員代號自動遞增（學員 A → B）
- 學員紀錄表與統計（完成人次、超時人次、平均用時），可一鍵複製為 CSV 貼到 Excel
- 5／6／8／10／12 分鐘快速預設；站別與任務可自訂；深淺色、全螢幕、語音播報、螢幕常亮
- 快捷鍵：空白鍵 開始／暫停、N 下一位、R 重設

## 本機預覽

直接用瀏覽器開啟 `index.html` 即可（提示音需先點擊頁面一次）。

## 部署到 Vercel（第二階段）

1. 將整個資料夾推上 GitHub repo。
2. Vercel → Add New Project → 匯入該 repo，Framework 選 **Other**，不需 build command。
3. 部署完成後取得 `xxx.vercel.app` 測試網址，分享給同仁試用。

## 資安與資料治理

- 所有設定與紀錄只存在使用者瀏覽器的 `localStorage`，不上傳任何伺服器。
- 請只使用「學員 A」「第 3 站」等模擬資料；禁止輸入真實姓名、病歷號、病歷內容。
- 外部資源僅載入 Google Fonts 字型；無第三方 JS 套件。
- 正式導入前依院內程序完成資安審查，並另行驗證計時準確性與斷網應變方式。
